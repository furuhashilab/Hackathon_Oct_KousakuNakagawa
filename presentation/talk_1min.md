SotM Asia と FOSS4G で何度も名前が出てきた「Overture Maps」を、今回はじめて触ってみました。

公式の Python ツールで、青山キャンパスのまわり約 2km 四方の Places データを取ってきたら、1 万 3 千件以上のお店や施設が入っていました。

1 件ずつ見ると、名前やカテゴリのほかに、「本当にあるか」の確からしさを表す confidence、リリースをまたいで使える固有番号の GERS ID、そして Meta や Foursquare など、どこから来たデータかを示す sources が付いています。

これを MapLibre で地図にして、クリックで中身を見たり、confidence やカテゴリで絞り込めるようにしました。

実際に見ると、山岳部が「山」に分類されていたりと、ツッコミどころもありました。Overture の特徴を、実際のデータから理解できたハッカソンでした。

---

**画面で見せるもの**

1. 地図全体（点の多さ）
2. 青山学院の POI をクリック → ポップアップ（confidence / GERS ID / sources）
3. confidence スライダーを動かして件数が減るところ
