## 1. きっかけ（約 20 秒）

SotM Asia OSAKA と FOSS4G Hiroshima では、いろいろな発表で「Overture Maps」という名前が出てきました。
Meta や Microsoft、Amazon などが参加して作っているオープンな地図データ、ということは知っていましたが、自分では一度も触ったことがありませんでした。
そこで今回は、Overture Maps を自分の手で使ってみることをテーマにしました。

## 2. 何をしたか（約 40 秒）

対象は、自分たちが毎日通っている青山キャンパスのまわりです。
Overture は世界中のデータなので、全部は取らずに、bbox という四角い範囲を決めて約 2km 四方だけを取り出しました。
公式の Python ツールを使うと、それだけで 1 万 3,322 件の Places、つまりお店や施設の POI が取れました。

ちなみに、手元の Windows ではセキュリティ機能に一部のライブラリがブロックされてコマンドが動かず、同じパッケージの Python の関数から取り出す方法に切り替えました。ここが一番つまずいたところです。

## 3. データの中身（約 50 秒）

1 件ずつ見てみると、名前とカテゴリのほかに、Overture らしい項目が 3 つありました。

1 つ目は confidence。その場所が本当に存在する確からしさを 0 から 1 で表しています。
ただ、Foursquare から来たデータは全部 0.77 で、Meta から来たデータは細かくばらばら。数字の意味がデータの出どころで違いそうだと気づきました。

2 つ目は GERS ID。場所ごとの固有番号で、毎月のリリースをまたいでも同じ場所を同じ ID で追いかけられます。

3 つ目は sources。Meta が約 8 割、Foursquare が約 15%、ほかに Microsoft や AllThePlaces など、どこから来たデータかと、そのライセンスが 1 件ごとに書いてあります。

## 4. 作ったもの（約 30 秒）

これを GeoJSON に変換して、MapLibre で Web 地図にし、GitHub Pages で公開しました。
点をクリックすると confidence や GERS ID、データソースが見られて、カテゴリや confidence で絞り込みもできます。
（ここでデモ：青山学院の POI をクリック → スライダーを動かす）

## 5. 気づき・今後（約 30 秒）

見ていくと、「青山学院大学山岳部」が山に、マンションが史跡に分類されているなど、自動分類らしいツッコミどころもありました。
ライセンスも提供元ごとに CDLA、Apache、CC0 と分かれていて、出典の書き方まで考える必要がありました。

次は、GERS ID を使って別の月のリリースと比べ、新しくできたお店やなくなったお店を見てみたいです。
