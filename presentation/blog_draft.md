# Overture Maps をはじめて触って、青山キャンパスのまわりを地図にしてみた

10 月の「FOSS4G Hiroshima / SotM Asia OSAKA 振り返りハッカソン」に参加しました。ルールは、イベントで紹介された技術のうち、自分にとって新しいものを 1 つ使うこと。私は Overture Maps を選びました。

作ったもの: https://furuhashilab.github.io/Hackathon_Oct_KousakuNakagawa/

## なぜ Overture Maps を選んだか

SotM Asia でも FOSS4G でも、Overture Maps の名前は本当によく聞きました。大きな企業が一緒になってオープンな地図データを作っている、というところまでは知っていたのですが、実際にどんなデータなのかは見たことがありませんでした。OpenStreetMap とはどう違うのか、企業のデータが混ざっているとはどういうことなのか。話を聞くだけではもやっとしていたので、自分で触って確かめることにしました。

## Overture Maps とは

Overture Maps Foundation が公開している、世界規模のオープンな地図データです。Amazon、Meta、Microsoft、TomTom などが参加していて、いろいろな会社のデータや OpenStreetMap のデータを、同じ形式にそろえて毎月公開しています。建物や道路、行政区画などいくつかの「テーマ」に分かれていて、今回はお店や施設が入っている Places というテーマを使いました。

## 何を作ったか

青山学院大学の青山キャンパスのまわり、だいたい 2km 四方の Places データを地図に表示する Web ページです。点をクリックすると、名前やカテゴリ、confidence、GERS ID、データの出どころが見られます。カテゴリや confidence で絞り込むこともできます。

対象を大学のまわりにしたのは、知っている場所の方が「このデータは合っている」「これはおかしい」が分かりやすいと思ったからです。

## どうやって作ったか

データの取得には、Overture 公式の Python ツール overturemaps を使いました。Overture は世界中のデータなので、全部をダウンロードするわけにはいきません。bbox と呼ばれる四角い範囲（西・南・東・北の座標）を指定して、その中だけを取り出します。これだけで 13,322 件の場所が取れて、正直ちょっと驚きました。渋谷と表参道にはさまれたエリアなので、お店がとにかく多いです。

取ったデータは、ブラウザで扱いやすい GeoJSON に変換しました。そのまま全部の項目を入れると重かったので、表示に使う項目だけに絞っています。

地図の表示には MapLibre GL JS を使い、背景には API キーのいらない国土地理院の淡色地図を使いました。最後に GitHub Pages で公開しています。

## 実際に触って気づいたこと

一番面白かったのは、1 件ずつに「どこから来たデータか」が書いてあることです。sources という項目に、Meta や Foursquare、Microsoft といった提供元と、そのライセンスが入っています。今回の範囲では 8 割くらいが Meta、15% くらいが Foursquare でした。ひとつの地図データの中に、ライセンスの違うデータが混ざっているというのは、話で聞くより実物を見た方がずっと分かりやすかったです。

confidence は、その場所が本当にある確からしさを 0 から 1 で表した数字です。最初は「これで信頼できるデータだけ選べるんだ」と思ったのですが、よく見ると Foursquare から来たデータは全部ぴったり 0.77 でした。一方で Meta から来たデータは細かくばらばらです。同じ confidence でも、出どころによって付け方が違うようなので、数字だけを見て判断するのは少し危ないなと感じました。

GERS ID は場所ごとに振られた固有の番号で、毎月のリリースをまたいでも同じ場所は同じ ID のままになる、というものです。今回は 1 回分のデータしか見ていないので、ありがたみはまだ実感できていません。

あと、カテゴリにはツッコミどころもありました。「青山学院大学山岳部」が山に分類されていたり、近くのマンションが史跡になっていたり。名前から自動で分類しているのかなと思います。こういうところは、知っている場所で見るからこそ気づけたことでした。

## 苦労したこと

一番つまずいたのは、データの取得です。公式のコマンドを実行したら、Windows のセキュリティ機能に一部のライブラリがブロックされて動きませんでした。セキュリティを切るのは違うと思ったので、同じパッケージの中にある、ブロックされない部分の関数を使ってデータを取り出す方法に変えました。

もうひとつは、情報の新しさです。Overture のスキーマは今も変わっていて、少し前まであった categories という項目が、2026 年 9 月のリリースでなくなっていました。ネットにある少し前の記事のコードは、そのままだと動きません。公式ドキュメントを見る大事さを実感しました。

ライセンスの扱いも思ったより考えることが多かったです。自分が作ったコードや文章は CC BY 4.0 にしましたが、Overture のデータそのものにそれを付けるわけにはいきません。提供元ごとに CDLA Permissive 2.0、Apache 2.0、CC0 と分かれているので、それぞれのライセンス本文と、Foursquare の NOTICE をリポジトリに入れました。

## 今後やりたいこと

せっかく GERS ID があるので、次は別の月のリリースと比べて、新しくできたお店やなくなったお店を地図にしてみたいです。OpenStreetMap の POI と重ねて、どちらにしかない場所があるのかも見てみたいと思っています。

Overture Maps は、名前だけ知っている状態から、中身を説明できる状態になれたのが今回の一番の収穫でした。
