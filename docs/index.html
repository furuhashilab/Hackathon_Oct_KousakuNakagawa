    Overture Maps とは？

    Amazon・Meta・Microsoft・TomTom などが参加する Overture Maps Foundation が公開している、世界規模のオープンな地図データです。 建物・道路・行政区画・場所（Places）などのテーマがあり、毎月更新されています。 複数の会社や OpenStreetMap などのデータを統合し、共通の形式（スキーマ）にそろえているのが特徴です。

    Places データとは？

    お店・飲食店・病院・学校など「人が訪れる場所」を点で表したデータです。 この地図では青山キャンパス周辺の約 2km 四方から - 件を取得しました （リリース -）。

    用語ミニ辞典

    POI
    Point of Interest の略。お店や駅など「地図上の気になる地点」のことです。
    confidence
    その場所が本当に存在する確からしさを 0〜1 で表した値です。1 に近いほど「実在する可能性が高い」とされます。正確さの保証ではない点に注意。
    GERS ID
    Global Entity Reference System の ID。地物ごとに振られた固有の番号（UUID）で、毎月のリリースをまたいで同じ場所を同じ ID で追いかけられます。
    bbox
    Bounding Box。「西・南・東・北」の座標で決める四角い範囲です。世界中のデータから必要な範囲だけを取り出すのに使いました。
    GeoJSON
    位置情報（座標）と属性（名前など）をまとめて保存できる JSON 形式の地理データです。ブラウザで扱いやすいので Web 地図でよく使われます。
    MapLibre
    MapLibre GL JS。Web ブラウザで地図を描くためのオープンソースの JavaScript ライブラリです。この地図の表示に使っています。

    Overture のデータ構造で面白かったところ

    • sources に「どの会社のデータから来たか」と、そのライセンスが POI ごとに入っています。
    • カテゴリは basic_category（分かりやすい大まかな分類）と taxonomy（階層つきの細かい分類）の 2 本立てです。旧 categories は 2026 年 9 月リリースで廃止されました。
    • 名前は names.primary のほか、言語ごとの別名（例: 英語名）を持てます。
